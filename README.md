# 體育課成績登記(115學年度・小一)

國小體育教師用的班級體育課成績登記網頁。老師可以自訂評量項目與配分、登錄學生表現、追蹤缺席補測,並查看班級統計。前端是靜態網頁,選用 Google Apps Script + Google Sheet 作為雲端資料庫。

## 頁面

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 體育課成績登記主頁面,老師直接用瀏覽器開啟,或用 GitHub Pages 發布 |
| `Code.gs` | 選用的雲端資料庫後端(Google Apps Script),部署成 Web App 後貼到 Apps Script 專案 |

## 核心功能

- 班級與單元管理:可切換不同學年度/學期/年級/班級與教學單元,同一批學生會跨單元保留。
- 評量項目自訂:新增、刪除、改名、調整順序;支援「分數(0-100)」「等級」「數據(含單位與方向)」「完成狀態」四種評量方式;配分可自訂,合計不是 100% 時會提醒,但不強制阻擋。
- 出席與補測:出席狀態有「出席、缺席待補測、請假、免測、已補測」,缺席/請假/免測不會被當成 0 分計算,班級平均只計算「已完成」登錄的學生。
- 一鍵式登分:等級類與完成狀態類評量改成單鍵按鈕登錄,方便在球場邊用平板快速操作。
- 搜尋/篩選、單步復原、CSV 匯出。
- 學生人數上限 25 人/班。

## 資料保存方式與雲端同步的分工(請務必先讀這一段)

本機一律先存在瀏覽器(localStorage)當離線備援,清除瀏覽器資料、換裝置或換瀏覽器會遺失,沒設定雲端同步前資料不會離開這台裝置。

設定好「雲端同步」(網址+金鑰)後,**名單跟成績的同步方向是分開設計的**,不是單純的上傳/下載整包資料:

- **學生名單 = Google Sheet 說了算**。您直接在試算表的「學生名冊」分頁新增/刪除/改名學生(欄位:班級代碼、座號、姓名),網頁只會「讀取」這個分頁,不會寫入或覆蓋它。改完 Sheet 後,到網頁按「雲端同步 → 同步名單」拉取最新名單。
- **評量設定、出席狀態、分數 = 網頁說了算**。您在網頁上調整評量項目、登記出席、輸入分數時,會**自動即時**存到後端的三個分頁(單元設定 / 出席與備註 / 成績資料),不需要手動上傳,右上角會顯示「同步中…/已同步/同步失敗」的小狀態。

換句話說:改名單去 Sheet 改,改分數在網頁改,兩邊不會互相覆蓋對方負責的部分。

金鑰保護只能擋一般人直接亂猜網址,不是正式校務系統等級的存取控制。學生成績屬於敏感資料,請不要公開分享 Web App 網址與金鑰,也不要把這個網站的網址公開張貼。

## 使用方式

不需要建置,直接用瀏覽器開啟 `index.html` 即可。也可以用 GitHub Pages 發布成網站(Settings → Pages → 選分支/資料夾)。

## 後端設定(Google Apps Script,選用)

如果不需要雲端同步,可以完全不設定這一段,網頁單機也能用(學生就用網頁上的「新增學生」自己輸入)。

1. 到 [script.google.com](https://script.google.com) 開一個新專案,或在一份 Google 試算表用「擴充功能 → Apps Script」開啟綁定的專案(建議用綁定試算表,這樣四個資料分頁會直接長在這份試算表裡)。
2. 把本專案的 `Code.gs` 整份內容複製,貼進 Apps Script 的程式碼編輯器(覆蓋預設的 `Code.gs` / `程式碼.gs`),按 Ctrl+S。
3. 左側「專案設定 → 指令碼屬性」,新增一筆屬性:名稱 `PE_API_KEY`,值自己設一個夠長的亂碼(這就是前端要填的「API 金鑰」)。
4. 上方函式選單選 **`setup`**,按執行(第一次執行會要求授權,照畫面同意即可)。這會在試算表建立四個分頁:「學生名冊」「單元設定」「出席與備註」「成績資料」。
5. 到「學生名冊」分頁,依照「班級代碼、座號、姓名」欄位填入您的班級學生(班級代碼自己訂,例如 `115-1-一年級-1班`)。
6. 「部署 → 新增部署作業」→ 類型選「網頁應用程式」→ 執行身分「我」,誰可以存取「任何人」→ 部署。複製產生的網址(結尾是 `/exec`)。
7. 回到 `index.html`,「新增班級」時把「雲端班級代碼」填成跟步驟 5 一樣的代碼;再點右上角「雲端同步」,把網址貼進「Apps Script 網址」、把 `PE_API_KEY` 的值貼進「API 金鑰」,按「同步名單」。

之後如果修改了 `Code.gs`,要「部署 → 管理部署作業 → 編輯 → 版本選新版本 → 部署」才會生效;只存檔不重新部署,Web App 還是跑舊版程式碼。

### 試算表分頁說明

| 分頁 | 誰維護 | 內容 |
| --- | --- | --- |
| 學生名冊 | 老師手動維護 | 班級代碼、座號、姓名 |
| 單元設定 | 網頁自動寫入 | 這個班級每個單元的評量項目設定(JSON) |
| 出席與備註 | 網頁自動寫入 | 每位學生每個單元的出席狀態與教師備註 |
| 成績資料 | 網頁自動寫入 | 每位學生每個單元每個評量項目的原始數據與換算分數 |

### 常見問題

- **同步名單失敗/連線失敗**:先確認部署的存取權限是「任何人」,且網址是 `/exec` 結尾(不是 `/dev`)。`/dev` 只有專案擁有者自己能用。
- **改了 `Code.gs` 卻沒有效果**:要重新部署「新版本」,單純存檔不會更新線上的 Web App。
- **同步名單後學生不見了**:表示 Sheet 的「學生名冊」分頁裡,該班級代碼下沒有這個座號,請檢查班級代碼與座號是否打錯。
- **改了評量項目名稱,舊分數好像不見了**:評量項目是用「名稱」在雲端比對身分,改名稱會被當成新項目。建議單元一開始就把項目名稱定好,盡量不要事後改名稱(配分、換算規則都可以改,名稱盡量不要動)。

## 尚未實作 / 已知限制

- 沒有多教師帳號登入,金鑰保護等級有限,請勿公開分享網址。
- 評量項目用「名稱」在雲端比對身分,改名稱會讓雲端資料跟本機對不上(見上方常見問題)。
- 沒有 CSV 匯入功能(目前只能匯出)。
- 多裝置同時編輯同一位學生的同一筆分數,後寫入的會覆蓋先寫入的(沒有合併機制)。
