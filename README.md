# 國小一年級體育課成績登記

課堂上用平板或手機單手登記，全班表現一眼看清。資料全部存在**您自己的 Google Sheet**，網站本身不含任何學生資料。

- 依據：《體育課程 雙語教學教案（一年級）》8 個主題、10 個單元（健康教案 5 主題 10 單元為選用，預設隱藏）
- 網站：https://lamp4615-design.github.io/pe-grades-grade1/
- 分類：跑步、跳繩、球類（最前面），另有平衡、呼拉圈、安全與態度、健康

## 第一次設定（約 5 分鐘，只做一次）

1. 開一份新的 **Google 試算表**。
2. 選單 **擴充功能 → Apps Script**，把編輯器裡原有的程式全部刪掉，貼上本專案的 [`Code.gs`](Code.gs)，按存檔。
3. 上方函式選單選 **`setup`** → 按 **執行**，依畫面授權。完成後會跳出視窗，顯示**教師通行碼**（請記下）。
   試算表會自動多出四個分頁，預設活動都已填好。
4. 右上角 **部署 → 新增部署作業 → 類型選「網頁應用程式」**：執行身分選「我」、誰可以存取選「所有人」→ 部署 → 複製「網頁應用程式網址」。
5. 開啟上面的網站，貼上**網址**與**通行碼**（記在這台裝置，之後不用再輸入）。
   其他裝置也想免輸入網址：開 `…/pe-grades-grade1/#api=網址` 一次即可。

**您唯一要做的事**：到「班級名單」分頁填 `班級 | 座號 | 姓名`（把範例那一列刪掉），再按網站右上角 ↻。

> 之後若修改了 Code.gs：**部署 → 管理部署作業 → 編輯 → 新版本 → 部署**，網址不變。

## 日常使用

**登記**：選班級、日期 → 點類別（跑步／跳繩／球類…）→ 選活動 → 頂列會顯示粗體的目標與三個門檻 → 每位學生一張卡片。

| 登記方式 | 怎麼點 |
| --- | --- |
| 次數／秒數 | 大數字框＋「−1／+1」，或直接點「優／達成／接近」帶入門檻值 |
| 動作要點 | 每個要點一顆大按鈕，勾選數自動換算等級 |
| 直接選等級 | 🌟優異　👍達成　🙂接近　💪需加油（再點一次取消） |

每張卡片都有「缺席」與 📝 備註；↺ 可清除該筆。點一下立刻變色，不用等網路。
便利功能：只看未登記、未登記全部設為達成（再改例外）、清除本次、Enter 跳下一位、跑步類「⏱ 全班計時模式」（按一次開始，學生衝線時點他的卡片蓋下秒數）。

**總覽**：全班等級分布與平均、各活動達成率、需要關注名單、尚未登記名單、學生×活動熱力圖（可依座號／需關注／表現好排序；可篩類別、單元、日期區間）。點學生看歷次成績與進步趨勢。支援列印與匯出 CSV（Excel 可直接開）。

**同步狀態**（畫面右下角）：`已同步 ✓` ／ `待同步 N 筆` ／ `離線`。離線也能繼續登記，連線後自動補送，不漏、不重複。

## 增減活動、調整門檻（不用改程式）

直接改 Google Sheet 的 **`活動設定`** 分頁，改完在網站按 ↻：

- 不想用的活動：`啟用` 改成 `N`；要用健康課程：把那幾列改成 `Y`
- 新增活動：在最下面加一列（`活動ID` 不可重複）
- `登記方式`：`count`（次數）、`time`（秒）、`checklist`（要點勾選，要點用「｜」隔開）、`level`（直接選等級）
- `評分方向`：`高`＝越大越好、`低`＝越小越好（如跑步秒數）
- 等級：達「優」門檻得 4、「達成」得 3、「接近」得 2，否則 1；缺席另外記錄、不計入平均
- 已有成績的活動請不要改 `活動ID`；改門檻會讓網站依新門檻顯示，Sheet 裡舊資料的「等級」欄維持寫入當時的值

> ⚠️ **所有門檻都是暫定建議值，不是教案原文，請依班級實際情況調整。**
> 「來源」欄：`教案`＝對應教案 PDF 單元；`自訂`＝老師自加（教案沒有跳繩單元，跳繩類全為自訂）。

## 安全提醒

- 網站是公開網址，**學生姓名只放在您的 Google Sheet**，由通行碼保護。請**不要**把真實名單或匯出的 CSV 提交進 GitHub。
- 通行碼存在 Apps Script 的「指令碼屬性」。忘記或想換：開試算表，選單 **體育成績 → 設定通行碼**。連續猜錯 10 次會暫時鎖定 10 分鐘。
- 通行碼只是簡易保護，請勿用與其他帳號相同的密碼。

## Sheet 分頁說明

| 分頁 | 誰寫 | 內容 |
| --- | --- | --- |
| 班級名單 | 您 | `班級｜座號｜姓名` |
| 活動設定 | 您（可隨時改） | 欄位：活動ID、類別、單元、活動名稱、圖示、登記方式、單位、評分方向、目標說明、勾選項目、優(4)、達成(3)、接近(2)、啟用、來源 |
| 成績 | 網站 | `時間戳｜日期｜班級｜座號｜姓名｜活動ID｜原始數值｜等級｜缺席｜備註｜唯一鍵`＋`勾選明細`（記錄勾了哪幾項，重新整理後才能還原勾選） |
| 單元一覽 | 您 | `單元｜主題｜教案名稱`（健康單元代號前加「健」） |

`setup()` 可重複執行：已存在的分頁與資料絕不覆蓋。誤刪預設活動可用選單 **體育成績 → 補齊預設活動**（只補回缺少的 ID，不動現有列）。

成績以 `日期|班級|座號|活動ID` 為唯一鍵，同一天同一位學生同一活動只會有一列，重複送出只會覆蓋。
