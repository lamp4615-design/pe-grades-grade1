# 體育課成績登記(115學年度・小一)

國小體育教師用的班級體育課成績登記網頁。老師可以自訂評量項目與配分、登錄學生表現、追蹤缺席補測,並查看班級統計。純前端靜態網頁,選用 Google Apps Script 作為雲端同步後端。

## 頁面

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 體育課成績登記主頁面,老師直接用瀏覽器開啟,或用 GitHub Pages 發布 |
| `Code.gs` | 選用的雲端同步後端(Google Apps Script),部署成 Web App 後貼到 Apps Script 專案 |

## 核心功能

- 班級與單元管理:可切換不同學年度/學期/年級/班級與教學單元,同一批學生會跨單元保留(不用每個單元重新輸入名冊)。
- 評量項目自訂:評量項目可新增、刪除、改名、調整順序;支援「分數(0-100)」「等級」「數據(含單位與方向)」「完成狀態」四種評量方式;配分可自訂,合計不是 100% 時會提醒,但不強制阻擋。
- 出席與補測:出席狀態有「出席、缺席待補測、請假、免測、已補測」,缺席/請假/免測不會被當成 0 分計算,班級平均只計算「已完成」登錄的學生。
- 一鍵式登分:等級類與完成狀態類評量改成單鍵按鈕登錄,方便在球場邊用平板快速操作。
- 搜尋/篩選、單步復原、CSV 匯出。
- 學生人數上限 25 人/班。

## 資料保存方式(請務必先讀這一段)

**預設情況下,資料只存在瀏覽器裝置內(localStorage)**,不會上傳到任何地方。清除瀏覽器資料、換裝置或換瀏覽器都會遺失,請定期用「雲端同步」或「匯出 CSV」備份。

網頁右上角有「雲端同步」按鈕,填入您自己部署的 Apps Script 網址與金鑰後,可以:
- **⬆ 上傳目前資料**:把目前瀏覽器裡的資料整包存到 Google 雲端硬碟,並同步鏡像到這份試算表的「班級名冊」「成績總表」「成績明細」三個分頁,方便直接用 Google Sheet 查看、列印或另存。
- **⬇ 從雲端下載**:取回雲端最新版本,覆蓋本機資料(會先跳確認視窗)。

這兩個動作都是**老師主動按才會傳輸**,不會自動背景同步,也不會即時雙向同步(兩台裝置同時編輯有衝突風險,請避免同時在兩個裝置改同一份資料)。試算表的三個分頁是**唯讀鏡像**:直接在 Google Sheet 上改內容不會回寫到網頁,下次「上傳」時會被覆蓋。

金鑰保護只能擋一般人直接亂猜網址,不是正式校務系統等級的存取控制。學生成績屬於敏感資料,請不要公開分享 Web App 網址與金鑰,也不要把這個網站的網址公開張貼。

## 使用方式

不需要建置,直接用瀏覽器開啟 `index.html` 即可。也可以用 GitHub Pages 發布成網站(Settings → Pages → 選分支/資料夾)。

## 後端設定(Google Apps Script,選用)

如果不需要雲端備份/Google Sheet 存檔,可以完全不設定這一段,網頁單機也能用。

1. 到 [script.google.com](https://script.google.com) 開一個新專案,或在一份 Google 試算表用「擴充功能 → Apps Script」開啟綁定的專案(綁定試算表可以讓「成績總表」等分頁直接長在這份試算表裡)。
2. 把本專案的 `Code.gs` 整份內容複製,貼進 Apps Script 的程式碼編輯器(覆蓋預設的 `Code.gs` / `程式碼.gs`),按 Ctrl+S。
3. 左側「專案設定 → 指令碼屬性」,新增一筆屬性:名稱 `PE_API_KEY`,值自己設一個夠長的亂碼(這就是前端要填的「API 金鑰」)。
4. 上方函式選單選 **`setup`**,按執行(第一次執行會要求授權,照畫面同意即可)。這會建立 Google 雲端硬碟上的資料檔,並在試算表建立三個分頁。
5. 「部署 → 新增部署作業」→ 類型選「網頁應用程式」→ 執行身分「我」,誰可以存取「任何人」→ 部署。複製產生的網址(結尾是 `/exec`)。
6. 回到 `index.html`,點右上角「雲端同步」,把網址貼進「Apps Script 網址」、把 `PE_API_KEY` 的值貼進「API 金鑰」。

之後如果修改了 `Code.gs`,要「部署 → 管理部署作業 → 編輯 → 版本選新版本 → 部署」才會生效;只存檔不重新部署,Web App 還是跑舊版程式碼。

### 常見問題

- **上傳/下載一直連線失敗**:先確認部署的存取權限是「任何人」,且網址是 `/exec` 結尾(不是 `/dev`)。`/dev` 只有專案擁有者自己能用。
- **改了 `Code.gs` 卻沒有效果**:要重新部署「新版本」,單純存檔不會更新線上的 Web App。
- **試算表分頁內容是舊的**:分頁只有「上傳目前資料」成功時才會重新產生,執行選單裡的「重新產生成績分頁」也可以手動重跑一次。

## 尚未實作 / 已知限制

- 沒有多教師帳號登入,金鑰保護等級有限,請勿公開分享網址。
- 雲端同步是手動單向上傳/下載,不是即時雙向同步,多裝置同時編輯會互相覆蓋。
- 沒有 CSV 匯入功能(目前只能匯出)。
- Google Sheet 的三個分頁是唯讀鏡像,直接編輯 Sheet 不會回寫到網頁資料。
